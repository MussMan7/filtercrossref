Find the furnace filter that actually fits your slot

FilterCrossRef is a plain reference for residential HVAC and furnace air filters: what the size on the label means, what the filter really measures, which brands run big or small, and which OEM part numbers are interchangeable. No sign-up, no pop-ups.

Before anything elseThe big number on the cardboard (for example 16x25x1) is a nominal name, not a measurement. Most 1″ filters are cut smaller on purpose, and thick 4–5″ media filters labeled with the same size can be completely different shapes from brand to brand. Read the 5-minute guide →

Size finder

Don’t have the old filter? Measure the slot (the opening the filter slides into) — width, length and depth — and see how to measure. The finder runs entirely in your browser.

How this site works

  • Dimensions come from published sources — manufacturer listings, spec sheets, or documented community measurements — and each table says where its numbers came from.
  • We don’t guess. If we couldn’t confirm an actual size, the cell says so instead of filling in a plausible number.
  • No health promises. We describe MERV ratings the way the test standard does (particle capture), not as medical advice.
